기능

- 화면 폭이 600px 이하로 줄어들면 미디어 쿼리를 통해 가로로 나열되던 메뉴를 세로 방향으로 정렬합니다.

- body.dark 선택자를 통해 다크 모드가 활성화되었을 때 배경색과 글자색을 어두운 톤으로 한꺼번에 전환합니다.

- 홈의 "인사 바꾸기"와 "다크 모드" 버튼을 누르면 문장과 배경색이 바뀌고 클릭 횟수가 1씩 오릅니다.

- 방명록에서 이름과 메시지를 적고 "남기기"를 누를 때마다 아래 목록에 한 줄씩 쌓입니다. 빈칸이면 안내 문장이 나옵니다.

이번에 배운것
- HTML을 활용한 웹페이지 구조 설계와 내비게이션 연결
    여러개의 독립된 페이지를 만들고, header와 nav 태그 안의 a 링크를 통해 페이지 간 이동이 가능한 웹사이트의 뼈대를 구축하는 방법을 배웠습니다.

- CSS Flexbox와 미디어 쿼리를 이용한 반응형 레이아웃
    display: flex와 gap 속성을 사용해 요소들을 정렬하고, 미디어 쿼리를 활용해 화면 폭이 좁아질 때 메뉴 배치가 세로 방향으로 바뀌는 디자인을 익혔습니다.

- 자바스크립트 이벤트 처리를 통한 동적 인터랙션
    addEventListener를 통해 사용자의 마우스 클릭을 감지하고 classList.toggle('dark') 로 웹페이지 전체의 테마를 전환하거나 클릭 횟수를 카운트하는 기능을 구현하는 법을 익혔습니다

-  Form 유효성 검사 및 동적 요소 추가
    방명록 제출시 event.preventDefaul() 로 페이지 새로고침을 막은 뒤, 이름이나 메시지가 비어있는지 검사하고 조건에 따라 안내 문구를 띄우거나
    document.createElement('li') 로 새로운 글을 화면에 추가하는 법을 배웠습니다.
